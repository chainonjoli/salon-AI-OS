# AIコンテンツファクトリー — 画面設計（工程3）

> 承認ステータス：**レビュー待ち**

デザイントーンは既存ページ（index.html / admin.html）と共通：
白基調（温白 `#FCFBF9`）＋くすみカラー、余白広め、明朝×ゴシック、角丸カード。
**ホームはタブバーなし・大きなボタンのみ**（要件どおり）。各画面から「←」で必ずホームへ戻れる。

## 画面遷移図

```
ホーム（f-home）
 ├─ コンテンツを作る（f-create）──[つくる]──▶ 生成中 ──▶ 生成結果（f-result）
 │                                                        ├─ 各コンテンツをコピー
 │                                                        ├─ まとめてコピー
 │                                                        └─ もう一度つくる
 ├─ 商品を登録する（f-products：一覧）
 │    └─ 商品の登録・編集（f-product-edit）
 │         └─ ［PDF・写真から取り込む］→ AI抽出 → フォームに自動入力 → 確認して保存
 ├─ 過去のコンテンツを見る（f-history：一覧）
 │    └─ タップ ──▶ 生成結果（f-result を閲覧モードで再利用）
 └─ 設定（f-settings）
```

## 各画面の設計

### 1. ホーム（f-home）

- ロゴ＋「AIコンテンツファクトリー」＋店名
- **縦に並んだ大きなボタン4つだけ**（1画面に収まる）
  - ✨ コンテンツを作る（メイン。アクセント色で最も目立つ）
  - 🧴 商品を登録する（登録件数バッジ）
  - 🗂 過去のコンテンツを見る（件数バッジ）
  - ⚙️ 設定
- AI未接続時は上部に細いお知らせ「いまはお試しモードです（設定からAI接続）」

### 2. コンテンツを作る（f-create）

タップ数最小の1画面完結：

1. **テーマ**：大きなテキスト欄1つ「例：乾燥肌向けの保湿ケア紹介」＋テーマのヒントチップ（季節ネタ等をタップで入力）
2. **商品を選ぶ（任意）**：登録商品がチップで横並び。タップで選択（1つ）。未登録なら「＋商品を登録する」導線
3. **［この内容でつくる］** 大ボタン

テーマまたは商品のどちらか一方だけでも生成可。
生成中はボタンが「AIが書いています…」表示に変わり、進行アニメーション。

### 3. 生成結果（f-result）

- 上部に「テーマ／商品名」の確認表示
- **8枚のカードが縦に並ぶ**。各カード：
  - 種類ラベル（📸 Instagram投稿 など）＋本文（折りたたみ：先頭6行＋「すべて見る」）
  - 右上に **［コピー］**（タップ→「コピーしました」トースト＋ボタンが✓に）
- 最下部：［まとめてコピー］［もう一度つくる］［ホームへ］
- 生成結果は**自動で履歴に保存**（保存ボタンを押させない＝ボタン削減）

### 4. 商品を登録する（f-products）

- 登録済み商品のカード一覧（商品名・ブランド名・一言）。タップで編集へ
- 下部固定 **［＋ 商品を追加］**
- 空のとき：イラスト＋「最初の商品を登録しましょう」＋追加ボタン

### 5. 商品の登録・編集（f-product-edit）

- 最上部：**［📄 PDF・写真から取り込む］**（AI接続時。ファイル選択→抽出中→フォームへ自動入力）
- フォーム7項目（各1入力欄・ラベルは平易な日本語）：
  商品名／ブランド名／特徴／効果／使用方法／おすすめの人／注意点
- ［保存する］大ボタン。編集時は［この商品を削除］（確認ダイアログ付き）

### 6. 過去のコンテンツを見る（f-history）

- 日付順リスト（新しい順）：「テーマ（or 商品名）・日付・種類数」
- タップ→生成結果画面（コピー可能）。左スワイプ不使用、削除は詳細画面のボタンで（誤操作防止）

### 7. 設定（f-settings)

- **お店のこと**：店名／業種（選択：エステ・美容室・ネイル・アイラッシュ・整体院・リラクゼーション・クリニック・その他）／お店のひとこと紹介／文体（やわらかい・きちんと・元気）
- **AI接続**：接続URL入力＋接続テストボタン＋状態表示（設置手順 docs/06 へのリンク）
- **データ**：書き出し（JSONダウンロード）／読み込み
- 保存は自動（入力のたび）。「保存ボタンを探す」体験をなくす

## UIルール（全画面共通）

- タップターゲットは最小44px。フォントは15px基準
- 破壊的操作（削除）のみ確認を挟む。それ以外は確認ダイアログを出さない
- 通知はすべて画面下部トースト（既存共通部品）
- 専門用語を使わない：「プロンプト」→「テーマ」、「エクスポート」→「書き出し」

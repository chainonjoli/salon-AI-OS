## 生成コンテンツの仕様

| コンテンツ | 形式・長さの目安 |
|---|---|
| Instagram投稿 | 本文300〜500字。冒頭にフック、絵文字は控えめ、最後に予約導線 |
| Instagramリール台本 | 15〜30秒想定。シーン別（0-3秒フック／本編／締め）のセリフ＋テロップ案 |
| LINE配信文 | 200字前後。挨拶→お知らせ→予約導線。絵文字1〜2個 |
| ブログ記事 | 800〜1200字。タイトル＋見出し3つ構成 |
| メールマガジン | 件名＋本文400〜600字 |
| ショート動画台本 | 30〜60秒想定（YouTube Shorts / TikTok向け）。ナレーション＋画面構成 |
| キャプション | 100字前後の汎用短文（写真に添える一言） |
| ハッシュタグ | 15〜20個。ビッグ／ミドル／スモールタグ＋地域タグをミックス |

## AI生成への入力（ナレッジ）

生成時にAIへ渡す情報：

1. **店舗プロフィール**（設定画面）：店名・業種・文体・店のひとこと紹介
2. **商品情報**（選択時）：登録済み7項目
3. **テーマ**：入力された自由文
4. **ルール**：薬機法NGワード回避・誇大表現禁止・媒体別フォーマット

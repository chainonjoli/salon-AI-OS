# AIコンテンツファクトリー — 要件定義（工程1）

> 承認ステータス：**レビュー待ち**（この文書への修正指示はいつでも反映できます）

## 1. プロダクトの目的

1つのテーマや商品情報を入力するだけで、SNS・販促コンテンツ一式（8種類）を自動生成する。
**スマートフォンだけで完結**し、パソコンが苦手なサロンオーナーでも迷わず使えること。

Salon AI OS における「AI広報」部署の実装であり、既存のナレッジ・ファースト設計
（`salon-config.js`）の上に載る。

## 2. ターゲットユーザー

- 主：個人サロンのオーナー（40〜60代、スマホ中心、SNS運用に時間を割けない）
- 将来：美容室・整体院・ネイル・エステ・クリニック・個人事業主（業種プリセットで対応）

## 3. 解決する課題

| 課題 | 解決 |
|---|---|
| 毎日の投稿文を考える時間がない | テーマ1つで8種類のコンテンツを一括生成 |
| 媒体ごとに文体・長さを変えるのが大変 | 媒体別に最適化された形式で出力 |
| 商品知識を毎回書き起こしている | 商品を一度登録すればAIが内容を反映 |
| カタログの情報を手で打ち直すのが苦痛 | PDF・画像からAIが商品情報を自動抽出 |
| 生成した文章の転記が面倒 | ワンタップコピー |

## 4. 生成するコンテンツ（8種類）

1. Instagram投稿
2. Instagramリール台本
3. LINE配信文
4. ブログ記事
5. メールマガジン
6. ショート動画台本
7. キャプション
8. ハッシュタグ

## 5. 機能要件（概要）

- **① コンテンツ生成**：テーマ／商品を入力 → 8種類を一括生成
- **② 商品登録**：商品名・ブランド名・特徴・効果・使用方法・おすすめの人・注意点。
  手入力に加え、**PDF・カタログ画像からのAI取り込み**に対応
- **③ AI活用**：登録商品と店舗プロフィール（店名・業種・文体）をAIが理解し、生成に反映
- **④ 出力**：各コンテンツをワンタップでコピー。履歴に自動保存

## 6. 非機能要件

| 項目 | 要件 |
|---|---|
| デバイス | スマホファースト（PCではスマホフレーム表示、既存ページと同様） |
| UI | 白基調・大きなボタン・専門用語なし・主要操作3タップ以内 |
| 動作環境 | 静的HTML1枚（GitHub Pagesでそのまま動作、サーバー不要） |
| AI接続 | Cloudflare Worker経由（既存 `server/worker.js` を拡張）。未接続時は**デモモード**でサンプル生成 |
| データ保存 | Phase 1はブラウザ（localStorage）。書き出し／読み込みでバックアップ可能 |
| 拡張性 | 業種プリセット・マルチテナント（`tenant_id`）を見据えたデータ構造（docs/13参照） |
| 法令配慮 | 薬機法・医療広告ガイドラインのNGワード（ナレッジの `style.ng`）を生成時に回避 |

## 7. スコープ外（Phase 1では作らない）

- SNSへの直接自動投稿（コピー→各アプリへ貼り付けの運用。誤爆防止のため意図的に外す）
- ログイン認証・複数ユーザー管理（Phase 2でサーバー側に実装）
- 画像生成（テキストコンテンツに集中）

## 8. 成功基準

- テーマ入力から8コンテンツ表示まで**3タップ**
- 商品登録（手入力）が1分以内、PDF取り込みが30秒以内
- 生成物が「そのまま投稿できる」品質（登録した商品情報・店舗の文体が反映されている）

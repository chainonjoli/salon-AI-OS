# 開発ロードマップ・今後追加すべき機能一覧

## Phase 1 — MVP（最初の3ヶ月）

**ゴール：「ナレッジ → AI応答 → LINE/予約導線」の縦串を1本、実サロン1店舗で回す。**

| # | 機能 | 備考 |
|---|---|---|
| 1 | AI受付（FAQ・営業時間・料金・アクセス・キャンセルポリシー・24時間） | 本プロトタイプの受付チャットを実AI化 |
| 2 | AI美容カウンセラー（選択式3問 → 提案 → LINE/予約導線） | 免責・NGワードガードレール必須 |
| 3 | ナレッジ管理（基本情報・文体・メニュー・FAQ・ルール・キャンペーン） | 保存→全AI反映の体験が最重要 |
| 4 | 予約導線（LINEリンク・Webフォーム・電話） | 予約システム自体は作らない |
| 5 | LINE導線（友だち追加・登録特典） | Messaging APIはまだ使わない |
| 6 | 管理ダッシュボード（AI対応件数・導線クリック・AIスタッフからの報告） | |
| 7 | セットアップウィザード（業種選択 → 15分で開店） | テンプレート販売の生命線 |

**Phase 1の成功指標**：時間外対応件数 / 相談→LINE登録率 / 受付→予約導線クリック率 /
オーナーのナレッジ更新頻度（週1回以上更新されていれば定着）

- 紹介プログラム（お客様の紹介リンク発行）
- サロン同士のナレッジテンプレート市場（優れたFAQ集・投稿テンプレの売買）
- ライセンス/ホワイトラベル管理画面（代理店が複数サロンを一括セットアップ）
- 経営レポート月次PDF（AIが1枚に要約して毎月1日に届ける）

## 優先順位の考え方

1. **オーナーの時間を直接減らす機能**（受付・フォロー・SNS）＞ 見栄えの機能
2. **対外送信は常に人間承認**を維持したまま自動化率を上げる
3. 外部API連携は「審査・仕様変更リスク」があるため、**リンク導線 → 半自動 → 全自動**の3段階で進める
4. どのPhaseでも、新機能は必ず「ナレッジを読む側」として実装する（ナレッジ・ファーストの原則）

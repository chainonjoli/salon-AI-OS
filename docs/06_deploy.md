# AI受付を「本物のAI」にする手順（Phase 1実装）

今のプロトタイプはサンプル応答で動いています。この手順を行うと、AI受付が
**本物のAI（Claude）としてナレッジに基づき自由な質問に答える**ようになります。

所要時間：約30分。プログラミング知識は不要です（画面の操作とコピペのみ）。

## 全体像

```
お客様のスマホ ──→ index.html（GitHub Pages等） ──→ ワーカー（Cloudflare） ──→ Claude API
                                                    ↑サロンナレッジはここに保存
```

- **ワーカー**＝AIへの取次役。サロンのナレッジと「守るべきルール」（医療断定禁止・
  価格はナレッジどおり等）を持っていて、お客様の質問と一緒にAIへ渡します
- APIキー（秘密の鍵）はワーカーの中だけに保存され、お客様のブラウザには渡りません

## 手順

### 1. AnthropicのAPIキーを作る（10分）

1. https://console.anthropic.com/ でアカウント作成
2. 支払い方法（クレジットカード）を登録し、クレジットをチャージ（まずは$5〜で十分）
3. 「API Keys」→「Create Key」→ 表示された `sk-ant-...` をメモ
   ※この鍵は**絶対に他人に見せない・HPに書かない**でください

### 2. Cloudflareにワーカーを作る（10分）

1. https://dash.cloudflare.com/ でアカウント作成（無料プランでOK）
2. 「Workers & Pages」→「Create」→「Create Worker」→ 名前を付けて「Deploy」
3. 「Edit code」を開き、中身を全部消して **`server/worker.js` の内容を貼り付け** →「Deploy」
4. ワーカーの「Settings」→「Variables and Secrets」→「Add」で
   - Type: **Secret** / 名前: `ANTHROPIC_API_KEY` / 値: 手順1の鍵
   を追加して保存
5. 画面に表示されるURL（`https://〇〇.〇〇.workers.dev`）をメモ

### 3. サイトとつなぐ（5分）

`salon-config.js` の `ai` の欄に、手順2のURLを入れます：

```js
ai: {
  endpoint: 'https://〇〇.〇〇.workers.dev'
},
```

これだけです。AI受付の画面に**入力欄が現れ**、自由な質問に本物のAIが答え始めます。
空欄に戻せばいつでもサンプル応答（デモモード）に戻ります。

### 4. 動作確認

AI受付を開いて、こんな質問を試してください：

- 「駐車場はありますか？」→ ナレッジどおりの案内＋LINE誘導
- 「シミが気になるんですが」→ 美容アドバイス＋断定しない言い回し
- 「予約したい」→ LINE予約ボタンが付く
- ナレッジにないこと（「ネイルはできますか？」）→「オーナーに確認します」と答えるはず

## 費用の目安

既定のモデル（Claude Opus 5：入力$5/出力$25 per 100万トークン）で、
1回の応答はおおむね**1〜3円程度**（ナレッジ部分はキャッシュされ2回目以降は割安）。
月300問答えても数百円のオーダーです。

もっと安くしたい場合は、ワーカーの環境変数に `MODEL` = `claude-haiku-4-5`
（入力$1/出力$5）を追加すると応答品質と引き換えにコストを1/5にできます。
まずは既定のまま品質を確かめるのがおすすめです。

## 運用の注意

- **ナレッジの更新**：価格やメニューを変えたら、`salon-config.js` と
  `worker.js` の `SALON` の両方を更新してください（Phase 2でナレッジDBに一元化予定）
- **公開範囲**：ワーカーの環境変数 `ALLOWED_ORIGIN` にサイトのURL
  （例 `https://chainonjoli.github.io`）を設定すると、自分のサイト以外から
  AIを呼べなくなります。公開後は設定を推奨
- **使いすぎ防止**：Anthropic Consoleの「Limits」で月の上限額を設定できます。
  必ず設定しておきましょう（例：月$10）
- **回答の見張り**：導入後1〜2週間は、実際の会話ログ（Cloudflareのログ画面）を
  ときどき確認し、おかしな回答があればナレッジやルールを直してください

## テンプレート販売時の構成

他サロンに納品するときは、サロンごとに：
1. ワーカーを1つ複製し、`SALON` の中身をそのサロンのナレッジに差し替え
2. そのサロン専用の `ANTHROPIC_API_KEY`（またはあなたの鍵＋上限設定）を設定
3. `salon-config.js` の `ai.endpoint` をそのワーカーのURLに

Phase 2以降は「1つのワーカー＋ナレッジDB（テナントID分け）」に統合し、
納品作業をさらに簡略化する設計です（docs/02 参照）。
